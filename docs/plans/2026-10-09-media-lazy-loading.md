# 主页媒体加载优化最终执行计划

2026-10-09：合并所有追加要求；本文件为唯一最终策略，旧的“仅点击下载”“不预取下一首”限制已删除。仅实现和本地验证，不提交、推送、部署或改线上资源。

## 保护范围

基于当前工作区增量修改，保留 Home.svelte 与 global.css 原有打字机、时间和按钮样式改动；保留文案、视觉、640px 断点、歌单顺序、音质、URL、天气和问候。博客 WallpaperSection.astro、background-player.js、music-manager.js 仅只读参考，不运行 sync:blog，不新增依赖或通用媒体框架。

## 默认背景

- SSR 用 picture 按 `(max-width: 640px)` 选择海报，仅当前端请求；海报 eager 占位与失败回退。
- 挂载确定断点后立即请求当前端视频并尝试静音播放。禁止等待页面 load、海报 load/decode、idle 或定时器。
- 默认背景、页面可见、非 reduced motion、非 saveData、未失败时启动；不支持 connection API 视为普通网络。
- playing 后显示视频，waiting/stalled 推迟尚未开始的壁纸预取；海报保持占位。失败或播放拒绝不循环重试。
- 隐藏暂停、恢复立即重查并复用；断点变化释放旧视频并立即切换新端，旧回调无效。省流/减少动态释放视频；卸载清理事件和资源。

## 随机壁纸

- 页面 load 后空闲预取当前端一个固定随机候选（排除当前图片），默认动态背景也可准备。缺少 requestIdleCallback 使用短定时器。
- 默认视频首次缓冲或 waiting/stalled 时延后未开始任务；视频稳定后恢复。隐藏/saveData 不开始后台工作，恢复重查；主动点击正常。
- 保留 URL、Image 和加载/解码 Promise；点击复用同一候选及未完成任务。加载解码成功才切换，不提前释放现有背景。
- 成功后消费候选，再准备一个；失败后台静默且不循环重试，明确点击可重试，失败保留背景。
- 断点切换与卸载取消调度、清理候选；版本隔离旧请求，最多一个当前候选，不请求其他端图库或整组图片。取消不能撤销已传输字节。

## 音乐初始化与首曲

- Home 仅类型导入 music；页面 load 后空闲或首次打开面板取先发生者动态 import，共用初始化 Promise、MusicPlayer 和订阅。
- 面板立即显示，初始化时禁用依赖播放器控件；模块失败可重试；迟到结果不打开面板/抢焦点，卸载后无实例创建或订阅。播放动作直接调用已准备播放器，不 await import。
- 普通可见网络后台预载第一首及封面一次，audio preload=auto、load，绝不 play，不恢复历史播放。用户已发起选曲/加载/播放时跳过，不覆盖用户选择。
- 首曲播放复用 loadedIndex；后台失败不变为当前播放错误，主动播放可重新加载。封面失败不影响音频，不批量下载歌单封面，不增加歌词请求。
- 关闭面板继续同一播放器播放；Home 卸载取消未运行后台任务与订阅，不重置用户当前播放。

## 临近结束预取

- 使用 timeupdate，当前播放、duration 有限正数、已播放至少5秒、剩余不超过20秒时预取下一首及封面。每个播放周期最多一次，不提前切歌、不交叉播放。
- 自动工作受可见性/saveData 限制，恢复后仍在阈值可准备；已开始请求不能保证立即停止。
- 列表顺序且末尾回第一首；随机抽一次非当前候选供手动下一首与自然结束复用；单曲/仅一首复用当前资源。
- 最多一个备用音频和备用封面，备用只 load 不 play，事件不能改当前播放状态。预取失败不暂停/跳歌/弹当前错误/循环重试。
- 切歌提升备用元素（加载未完成也复用），清理旧播放监听/资源，只有一个实际播放。备用失败时一次正常加载，错误遵循显式重试。
- 选其他曲目、上一首、模式变化清理不匹配候选，以身份/版本隔离旧 Promise 与事件。新播放周期阈值后再准备，禁止递归预取。
- preload=auto 可能下载整首 FLAC；数量上限不是字节上限，不承诺无缝切歌或固定性能收益。
