# 素材与许可说明

本仓库采用"代码与素材分开授权"：源代码以 [MIT License](../LICENSE) 开源；壁纸、头像、品牌图片、字体、音乐等素材**不在** MIT 许可范围内。

## MIT 许可覆盖的内容

- `src/` 下的组件、脚本、样式与测试（`src/data/home.json` 中的个人资料除外，见下表）
- `scripts/` 下的构建与维护脚本
- 根目录的配置文件，如 `astro.config.mjs`、`wrangler.jsonc`、`package.json`、`tsconfig.json`
- `docs/` 下的文字文档

## 复用项目时

请替换个人资料、联系方式、备案信息、媒体地址及品牌内容，并确认所用素材的发布与再分发权限。字体继续遵守各自随附许可，不应移除版权及许可记录。

如需反馈素材署名或权利问题，可通过[主页](https://dcelysion.cn/)提供的邮箱联系。
