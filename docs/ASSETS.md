# 素材与许可说明

仓库用于展示 DcElysion 个人主页的实现。公开可见不等于所有内容都适用同一开源许可；目前未为整个项目添加统一的 LICENSE。

| 内容 | 仓库中的许可与来源记录 |
| --- | --- |
| MiSans | 许可见 `public/assets/fonts/MiSans-License.pdf`；源字体与分包维护说明见 `resources/fonts/README.md`。 |
| 霞鹜文楷 | 随附 `public/assets/fonts/LXGWWenKai-OFL.txt`；子集来自霞鹜文楷 Regular v1.530。 |
| 壁纸、头像、海报与品牌图片 | 用于本个人站点展示；仓库尚未建立逐项作者、原始链接与再分发授权清单，不据此承诺可自由复用。 |
| 音乐与封面 | `src/data/home.json` 保存外部资源地址，仓库不包含音频文件；外链并不构成音乐或封面的使用授权。 |
| README 页面截图 | 来自本项目在线页面，包含页面展示的第三方素材，不另行授予其中素材的使用权。 |

复用项目时，请替换个人资料、联系方式、备案信息、媒体地址及品牌内容，并确认所用素材的发布与再分发权限。字体继续遵守各自随附许可，不应移除版权及许可记录。

如需反馈素材署名或权利问题，可通过[主页](https://dcelysion.cn/)提供的邮箱联系。
